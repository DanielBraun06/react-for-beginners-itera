# Навчу грати в шахи за 60 секунд: Reel для @daniil_chess

Вертикальний моушен-ролик без голосу: правила шахів пояснюють 3D-дошка, кінетична типографіка й саунд-дизайн. Від хука до CTA рівно 60 секунд, а таймер угорі весь час відраховує час, тож обіцянку з хука видно на екрані.

| Параметр | Значення |
|---|---|
| Формат | MP4 (H.264 High, yuv420p, BT.709) + AAC 48 kHz 256 kbps |
| Розмір | 1080 × 1920 (9:16), 30 FPS |
| Тривалість | 60.0 с |
| Гучність | −14 LUFS, true peak ≈ −1.2 dBFS (норма Instagram) |
| Палітра | `#FF5204`, `#000000`, `#FFFFFF` |

## Файли

- `output/chess_rules_60s.mp4`: фінальний ролик
- `output/cover.jpg`: кадр для обкладинки

## Структура

| Час | Розділ | Що на екрані |
|---|---|---|
| 0–4 | Хук | 3D-кінь крупним планом, «НАВЧУ ГРАТИ В ШАХИ / ЗА 60 СЕКУНД», стартує таймер «засікай час» |
| 4–10 | Дошка | 31 фігура падає на свої місця каскадом; «дошка 8×8, 32 фігури», «білі ходять першими», e4 / e5 |
| 10–14 | Мета | Камера облітає дошку до чорного короля: «не з’їсти всі фігури, а поставити мат королю» |
| 14–18.5 | Пішак | вперед на 1, з початку на 2, б’є по діагоналі (взяття exd5) |
| 18.5–22 | Тура | промені по прямих, хід d4–h4 |
| 22–25.5 | Слон | діагоналі, не змінює колір клітинки, d4–g7 |
| 25.5–29 | Ферзь | тура + слон, d4–h8 |
| 29–32.5 | Король | 8 сусідніх клітинок, e4–e5 |
| 32.5–37 | Кінь | буква «Г» (2 + 1), стрибок через оточення з пішаків |
| 37–43.5 | Шах | тура a1–e1, промінь по вертикалі e, король тікає на d7: «втекти, закритись або побити» |
| 43.5–52 | Мат | мат по останній горизонталі (Re8#), поля f8/h8 під боєм, король падає |
| 52–60 | CTA | «Тепер ти знаєш правила шахів», аватар, @daniil_chess, кнопка «ПІДПИСАТИСЯ» |

## Звук

Без семплів і без голосу, все синтезовано в `src/audio.py` (голоси й мастеринг у `src/sfxlib.py`).
Сценарій (`src/script.js`) експортує `src/cues.json`: кожне приземлення фігури, підсвітка клітинок, промінь, удар тексту й перехід камери мають свій звук рівно в тому кадрі, де відбувається дія.
Шари: дерев’яні удари фігур (окремий тембр на кожен тип), саб-удари, braam, whoosh під облети камери, пентатонічні «блипи» під промені ходів, лазерний zap, тік таймера, райзер і тиша перед матом, bass drop на мат.
Музика легка (120 BPM, ре мінор → ре мажор у CTA) і стоїть під звуками: вона тримає темп, а не грає головну роль.

## Перезбірка

```bash
npm i                                           # three.js
cd src
node render.mjs cues                            # таймінги звуків → cues.json
node render.mjs frames /tmp/frames 3            # 1800 кадрів (Playwright + Chromium, WebGL через SwiftShader)
python3 audio.py ../output                      # score.wav (numpy + scipy + pyloudnorm)
ffmpeg -framerate 30 -i /tmp/frames/f%04d.png -i ../output/score.wav \
  -vf "scale=out_color_matrix=bt709:out_range=tv,format=yuv420p" -color_primaries bt709 -color_trc bt709 -colorspace bt709 \
  -c:v libx264 -preset slow -crf 16 -maxrate 14M -bufsize 20M -profile:v high \
  -c:a aac -b:a 256k -ar 48000 -movflags +faststart -shortest ../output/chess_rules_60s.mp4
```

Окремі кадри для перевірки: `node render.mjs stills 1.0 46.3` → `output/stills/`.
Код: `src/world.js` — 3D (дошка, фігури, підсвітки, промені), `src/script.js` — сценарій, камера, тексти, `src/main.js` — композитинг і типографіка, `src/lib2d.js` — 2D-хелпери.
