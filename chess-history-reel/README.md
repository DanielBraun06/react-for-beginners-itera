# Історія шахів: Reel для @daniil_chess

30-секундний вертикальний моушен-ролик про шлях шахів з Індії через Персію до Європи.

| Параметр | Значення |
|---|---|
| Формат | MP4 (H.264 High, yuv420p, BT.709) + AAC 48 kHz |
| Розмір | 1080 × 1920 (9:16), 30 FPS |
| Тривалість | 30.0 с |
| Гучність | −14 LUFS, true peak ≈ −1.2 dBFS (норма Instagram) |
| Палітра | `#FF5204`, `#000000`, `#FFFFFF` (з фірмового стилю ProstoChess) |

## Файли

- `output/chess_history_reel.mp4`: фінальна версія з українською озвучкою
- `output/chess_history_reel_no_voice.mp4`: та сама версія без голосу (музика й ефекти), щоб записати власну озвучку
- `output/cover.jpg`: кадр для обкладинки Reels

## Звук

Весь звук синтезований у `src/audio.py`, без сторонніх семплів, тож проблем з авторськими правами немає:

- **Переходи:** брам, суб-удари, свуші зі свіпом фільтра, райзери, реверс-свели, блискавка з громом
- **Індія:** тампура (джаварі-«цвітіння» обертонів), табла (na/ge), сітарна фраза в ладу Бхайрав, слон
- **Персія:** сантур (лад Хіджаз), даф з дзвіночками, дзвіночки каравану, вітер пустелі
- **Європа:** церковні дзвони, хор (формантний синтез), литаври з роллом-наростанням, мідні в кульмінації, дзвін меча
- **UI/текст:** тики під кожну літеру, «попи» плашок, дерев'яні стуки фігур, клацання клавіш під набір ніку, тап і chime на кнопці
- **Мікс:** sidechain-дакінг музики під голос, реверберація, лімітер з lookahead, нормалізація до −14 LUFS

## Перезбірка

```bash
# 1. кадри (Playwright + Chromium, ~1 хв)
cd src && node render.mjs frames /tmp/frames 4
# 2. звук (numpy + scipy + pyloudnorm)
python3 audio.py ../output
# 3. збірка
ffmpeg -framerate 30 -i /tmp/frames/f%04d.png -i ../output/mix.wav \
  -vf "scale=out_color_matrix=bt709:out_range=tv,format=yuv420p" \
  -c:v libx264 -preset slow -b:v 10M -maxrate 14M -bufsize 20M -profile:v high \
  -c:a aac -b:a 256k -movflags +faststart -shortest ../output/chess_history_reel.mp4
```

Попередній перегляд окремих моментів: `node render.mjs stills 1.5 13.2 22.9` → `output/stills/`.

Таймінги озвучки лежать у `src/timeline.json`. Озвучка генерується офлайн-моделлю Piper `uk_UA-ukrainian_tts` (голос «mykyta») через `src/tts.py`, тексти з наголосами в `src/lines.py`. Щоб замінити голос на свій, запиши фрази у `assets/vo/vo_<ключ>.wav` і перезбери звук.
