# Історія шахів за 60 секунд: Reel для @daniil_chess

Вертикальний моушен-ролик без озвучки: історію розповідають кінетичний текст і музика. Шахи пройшли шлях від Індії VI століття до сотень мільйонів гравців сьогодні.

| Параметр | Значення |
|---|---|
| Формат | MP4 (H.264 High, yuv420p, BT.709) + AAC 48 kHz 256 kbps |
| Розмір | 1080 × 1920 (9:16), 30 FPS |
| Тривалість | 60.0 с |
| Гучність | −14 LUFS, true peak ≈ −1.2 dBFS (норма Instagram) |
| Палітра | `#FF5204`, `#000000`, `#FFFFFF` |

## Файли

- `output/chess_history_60s.mp4`: фінальний ролик
- `output/cover_60s.jpg`: кадр для обкладинки
- `output/v1_30s/`: попередня 30-секундна версія з синтетичною озвучкою (архів)

| 12–22 | Персія, VII ст. | «ШАТРАНДЖ», удари «ШАХ / МАТ» = «король переможений», ферзь-радник ходить на 1 клітинку |

## Звук

Весь звук синтезований у `src/audio60.py` (бібліотека голосів — `src/sfxlib.py`), без сторонніх семплів:
кожна епоха має свій інструментарій (тампура, табла, сітар → сантур, даф → плак-остинато мапи → хор, дзвони, литаври, мідні → тік-так годинника як ритм → електроніка), плюс свуші, удари, тики під літери, стуки фігур, тріскіт лічильника років, глітчі, «попи» гравців у пентатоніці.

## Перезбірка

```bash
cd src
node render.mjs frames /tmp/frames 4          # 1800 кадрів, ~2 хв (Playwright + Chromium)
python3 audio60.py ../output                  # score60.wav (numpy + scipy + pyloudnorm)
ffmpeg -framerate 30 -i /tmp/frames/f%04d.png -i ../output/score60.wav \
  -vf "scale=out_color_matrix=bt709:out_range=tv,format=yuv420p" \
  -c:v libx264 -preset slow -b:v 8M -maxrate 12M -bufsize 16M -profile:v high \
  -c:a aac -b:a 256k -movflags +faststart -shortest ../output/chess_history_60s.mp4
```

Окремі кадри для перевірки: `node render.mjs stills 16.2 25.6 41.5` → `output/stills/`.
Код: `src/lib.js` — малювання (фігури, архітектура, текст, частинки), `src/scenes60.js` — сцени й таймінги.
