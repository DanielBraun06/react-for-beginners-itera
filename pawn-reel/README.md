# «Пішак, якого всі недооцінювали»: Reel для ProstoChess

45 секунд, 1080 × 1920, 30 fps. 3D-мультик про пішака, який по одній клітинці проходить від e2 до d8 і стає ферзем. Фігури зроблені як дерев'яні іграшки, сцену освітлює настільна лампа. Озвучка українською, субтитри вшиті в кадр.

| Параметр | Значення |
|---|---|
| Файл | `output/pawn.mp4`: H.264 High, yuv420p, BT.709, AAC 48 kHz 256 kbps |
| Тривалість | 45.0 с, 1350 кадрів |
| Гучність | −14 LUFS, true peak ≈ −2.2 dBTP |
| Обкладинка | `output/cover.jpg` |
| Голос | TTS ElevenLabs turbo v2.5 (голос George) через Sibrik, `public/voice_tts_raw.mp3` |

## Що в кадрі

Камера знімає все одним дублем, без склейок. Ходи шахово коректні: пішак іде по одній клітинці (e2→e3→e4→e5), чорний слон стоїть на d6, тобто по діагоналі попереду, і пішак б'є його навскіс (exd6). Далі d7, d8 і перетворення на ферзя.

| Час | Подія |
|---|---|
| 0–5 | Крупний план пішака на e2. Його тінь на дошці має форму ферзя: це насіння, яке окупиться у фіналі |
| 5.4–8 | На дошку падають король, ферзь, слон і кінь. Кінь стрибає (g1–f3), слон летить (c1–g5), ферзь ковзає (d1–a4), пішак косо на них поглядає |
| 8–13 | Три ходи по одній клітинці, на e5 пішак втомлюється і дістає хустинку |
| 13–19 | Згори падає чорний слон (d6), лампа мерехтить, музика стихає, гуде низький дрон |
| 19–21 | «Секрет»: пішак хитро озирається на глядача, на дошці загоряються стрілки «прямо» і «навскіс» |
| 22.5 | Удар exd6: слон падає на бік, над ним крутяться зірочки, хустинка лишається лежати на e5 |
| 26–34 | Золоте світіння на d8, музика зникає, лишаються кроки й дерев'яне «серцебиття» |
| 35 | Золотий спалах, пішак виростає у ферзя, у світлі з'являється корона |
| 38–42 | Ферзь озирається назад на свій шлях, усміхається і підморгує на «Підписуйся» |
| 44 | Клацає вимикач, лампа гасне, у темряві з'являється підпис «ProstoChess» |

## Як підставити свій голос

1. Запиши той самий текст (сценарій у `src/timeline.json`, поле `voice[].text`) і поклади файл у `public/voice.mp3`.
2. У `src/timeline.json` для кожної фрази виправ `src`: це початок і кінець фрази у твоєму файлі, в секундах. Знайти їх допоможе команда:

```bash
ffmpeg -i public/voice.mp3 -af silencedetect=noise=-35dB:d=0.25 -f null - 2>&1 | grep silence_
```

3. Поле `at` (коли фраза звучить у ролику) не чіпай, тоді анімація і субтитри лишаться синхронними. Далі перезбери звук і відео, як описано нижче.

## Перезбірка

Потрібні Node 22, Playwright із Chromium, ffmpeg, Python із `numpy scipy pyloudnorm`.

```bash
npm install
```

```bash
cd src && node render.mjs frames /tmp/pawn_frames 3
```

```bash
cd src && python3 audio.py ../output
```

```bash
ffmpeg -y -framerate 30 -i /tmp/pawn_frames/f%04d.jpg -i output/mix.wav -vf "scale=out_color_matrix=bt709:out_range=tv,format=yuv420p" -c:v libx264 -preset slow -crf 16 -profile:v high -c:a aac -b:a 256k -movflags +faststart -shortest output/pawn.mp4
```

Рендер займає близько 15 хвилин на 4 ядрах (WebGL через SwiftShader). Окремі кадри для перевірки: `node render.mjs stills 13.9 22.5 35.1` → `output/stills/`. Обкладинка: `node render.mjs cover`. Якщо відкрити `src/index.html` через будь-який локальний сервер, ролик програється в браузері в реальному часі.

## Код

- `src/timeline.json`: єдиний таймлайн. Звідси беруть час і анімація, і субтитри, і звук, тож усе синхронно за побудовою.
- `src/scene.js`: сцена three.js. Фігури точені (LatheGeometry), текстура дерева процедурна. Риг пішака: сквош і стретч, очі, брови, руки-кілочки, хустинка. Морф пішак→ферзь зроблений інтерполяцією профілю. Тінь-ферзь кидає невидимий двійник. Камера рухається по Catmull-Rom із дрейфом «з рук», в кадрі є пил у промені, блум, зерно і субтитри.
- `src/audio.py`: lo-fi на 80 BPM (електропіано, стук фігури замість снейра, вініл), SFX на кожну подію, обробка голосу, лімітер і нормалізація до −14 LUFS. Усе синтезоване, без семплів, тому Content ID не спрацює.
- `src/render.mjs`: покадровий рендер через Playwright.
- `plan/creative.md`: режисерський план (заборонені штампи, насіння й урожай, фірмовий момент).
